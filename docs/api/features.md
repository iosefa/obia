# Raster Features API

::: obia.features.extract.extract_features

::: obia.features.spectral.compute_index

::: obia.features.texture.TextureConfig

Available feature names can be inspected with `SPECTRAL_FEATURES`,
`SPECTRAL_INDICES`, `SHAPE_FEATURES`, and `GLCM_FEATURES` from `obia.features`.
See the [raster feature guide](../usage/raster-features.md) for formulas, units,
mask handling, and configuration examples.
